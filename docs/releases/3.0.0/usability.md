# Usability

Target in the plan: a new user installs, approves a change set, and gets a next action in about ten minutes, observed with at least five people who do not already know SSD.

**Status: NOT_RUN.** No pilot session was held. This file is the protocol, not a result.

## Protocol for the owner

1. Give the person the clone instructions in `README.md`. Do not sit with them for the first ten minutes.
2. Ask them to run setup, read the proposed file list, and say what `/ssd` tells them to do next.
3. Ask whether a passing gate means they shipped. The expected answer is no.
4. Interrupt a run and ask them to resume it. Record whether they think shipping authority came back.
5. Write what confused them. Do not collect source, prompts, or secrets.

Until that record exists, the ten-minute target is unmet.
